# E7-A LSP fixture shapes

- `lsp-method-cases.json` — one-to-one lifecycle/document/analysis/cancellation method mappings and unsupported operations.
- `lsp-framing-position-cases.json` — stdio framing, JSON-RPC, Unicode positions, document versions, broken-pipe, and source-injection cases.
- `CHECKSUMS.json` — service/spec/profile/platform/vector/member freeze gate.

Null implementation/spec/checksum values are allowed only while implementation state is `not-started`.
