# E7-A MCP fixture shapes

- `mcp-tool-resource-cases.json` — static descriptor, one-call mapping, exact resource, candidate/mapping/selection/context, and rejected generic/dynamic surfaces.
- `mcp-framing-lifecycle-cases.json` — initialization, framing, cancellation, progress, slow-client, broken-pipe, shutdown, authorization, and source-injection cases.
- `CHECKSUMS.json` — service/spec/profile/platform/vector/member freeze gate.

Null implementation/spec/checksum values are allowed only while implementation state is `not-started`.
