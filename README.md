# WoW Dev Framework

Документационный репозиторий для проекта **WoW Dev Framework**.

## Назначение
- Хранить архитектурные документы и описания платформы для разработки WoW-аддонов.
- Служить единым источником документации и планов по развитию до момента появления рабочего кода.
- Обеспечить изолированное место для проектной документации без смешивания с исходным кодом других репозиториев.

## Текущее состояние
- Репозиторий приватный.
- Код и исходники пока не добавляются.
- CI/CD пока не настроен (отключён/не используется).
- Для новых задач ожидается добавление документации и процессов верификации.
