# Native project, TOC and lexical XML graph roles

The explicit library entry
`wow_project::graph::build_platform_graph_proposal_plan_with_structural_roles`
extends the captured direct graph over one genuine retained platform ProjectView.
It requires the existing raw-inventory configuration, selects native
`wow-project/platform-direct-producers/3`, stage producer version `3` and registry
`wow-project.source-load` version `18` before constructing the input generation,
foundation or raw prelude. Follow the existing ordered
[admission and finish protocol](PLATFORM_DIRECT_PRODUCERS.md).

The adapters consume the original source/package receipts, selected native load
plans, TOC facts, XML lexical indexes and captured support. They add no parser,
analyzer, source acquisition or disk fallback. Inventory spans are projected
first; XML occurrences join those exact existing span proposals.

| Owner | Added roles | Authority |
| --- | --- | --- |
| Inventory | `source_project` and project-to-package/file/raw-member plus package-to-raw-member Contains relations | Proven retained source observations and original declared package roots; admission inventory remains Partial. |
| TocLoad | Selected TOC manifest/variant, load occurrences and declared load policy; Defines, Contains, Loads and LoadsBefore relations | Derived static topology from exact native facts and load-unit receipts. Conditionally reachable file loads remain Possible. |
| XmlStructure | Qualified XML document/occurrence, script site, load site and parent-reference entities; lexical containment, captured-span ownership and guarded include/external-script targets | Proven source observations. Parent resolution/order/cycle and load uncertainty remain typed source state. |

The project key includes the actual project and project/source snapshots, source
profile/content-manifest/admission digests and a package-authority digest that
binds the existing native binding together with the original request, including
physical roots, variant declarations and context. One genuine raw
member, chosen by original path order, supplies a byte witness. This witness is
not proof of a complete inventory. Project authority comes from the full held
native binding and source-receipt comparison. Every original raw member retains
its project edge; every segment-prefix match against an original declared package
root retains its package edge, including overlaps. Package-qualified Main paths
do not supply physical root authority.

TOC roles preserve the selected document/flavor, source ordinal, selection,
conditions digest, repetition, bootstrap, load-unit witness digest, static phase,
order group and reachability. Unselected variant receipts remain in the original
package plan. File targets require an Included native unit, an actual captured
file and non-Unreachable package state. LoadsBefore describes lexical TOC source
order; it does not establish client execution order.

XML identity retains the package/selected-TOC scope, qualified document and exact
document digest together with the original occurrence ID. Script state is joined
to the native lexical record. Parent references retain their native resolution,
order and cycle state without producing runtime ParentOf. Load sites preserve
records, issues, reachability, static phase and an explicit outcome. Include and
external-script edges require a unique Included native loader receipt, a
registered captured target and the applicable issue/reachability guards. Missing,
excluded, repeated, cyclic, unsupported and unresolved outcomes do not create a
target edge. Canonical state is bounded by the existing 4096-byte graph-value
limit; oversized state refuses rather than being clipped.

Raw endpoints resolve the original raw Producer proposal and accepted receipt
under the exact input scope. Cross-stage endpoints use accepted input-generation
IDs. Finish checks all partitions and returns the held native evidence catalog.
The original handles/evidence and TOC/XML outcome streams remain intact.

Contains, Defines and LoadsBefore coverage remains scoped/Partial with negative
authority false. The existing conservative cumulative 4 MiB serialized metadata
allowance, node/edge caps and combined 200,000 assertion ceiling still apply;
the allowance is not a process resident-memory bound. Cancellation, invalid
support or incompatible predecessor admission prevents a finished capability.

Native /1 and /2 remain separate. Source /22, service request12/result19 and
replay/storage v9 retain native /1; /3 adds no configuration, service, CLI or
replay selector. The registry-16 raw excerpt binder does not admit registry18.
The separate [native /4 entry](PLATFORM_XML_SOURCE_MAPS.md) adds virtual-Lua source
mapping; /3 retains its existing roles and recipe. Full XML object/region classification, fingerprints,
bounded SkeletonInputView and source transport remain open, alongside full
W17/E3/package acceptance and W18-W26. Gethe preparation remains deferred until
the product implementation/build stage is complete.
