## How to read the status

- **Document `read`:** the full baseline document was read and its relevant
  ideas extracted. This does not verify its claims about implementation.
- **Document `partial`:** only the stated portion was inspected.
- **Code `traced`:** the relevant listed implementation chain was followed.
  This is source evidence, not a claim about every function in that file.
- **Code `partial`:** selected branches/owners were inspected; the full
  behavior described by the document was not established.
- **Code `not_checked`:** implementation was not traced for that document.
  Any code references in that row are navigation, not verification evidence.
- **Code `not_applicable`:** contributor policy, notices or descriptive
  material without an implementation claim being checked in that row.

No tests, addon executions, editor sessions or performance measurements were
run for this review. The owner's instruction defers tests until functional
completion. The supplied Claude run counts remain **reported**, without an
independent rerun or raw run log. Compilation/CI evidence has a different scope.
