# Scope decision

## ADR-058 — A focused WoW development tool

Accepted by explicit owner direction, 2026-10-18 UTC. EmmyLua, native Ketho
annotations, editor-independent addon checking and Blizzard UI source search
replace the E0–E7 platform plan. Conflicting compatibility, cryptographic,
provider, plugin, lineage, storage-administration and release-system obligations
are retired even where their implementation still exists. They are removal work,
not mandatory unfinished product features.

[ARCHITECTURE.md](ARCHITECTURE.md) is the sole product manifesto.
[AUDIT.md](AUDIT.md) records the complete source/architecture basis for the
rewrite. [IMPLEMENTATION.md](IMPLEMENTATION.md) maps target owners and replacement
routes; [REFACTOR_QUEUE.md](REFACTOR_QUEUE.md) orders work. Do not duplicate these
rules in package contracts or add a decision record for each helper.

Superseded decisions and audits remain available in Git history.
