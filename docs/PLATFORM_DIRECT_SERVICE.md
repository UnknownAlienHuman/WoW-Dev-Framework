## Native composition

The service admits raw inventory first, then Inventory, TocLoad,
AnalyzerStructure and XmlStructure in the native plan's order. Each stage sees
its admitted predecessor and retains the native producer version and coverage.
The native plan finishes against that source-only owner before recognizers run.

Calls, construction, mixins, script/state access, signal/hook/library families,
TOC, XML, saved-variable roots and core Read/Write then use the existing native
owners. The held source capability supplies exact Producer addresses. Common
analyzer consumers receive the actual AnalyzerStructure partition; mixed
consumers receive native assertion inputs. State/script result metadata retains
its genuine assertion envelope, with legacy recognition fields omitted.

Crosswalks validate the original source partition against the current native
partition, plus registry, foundation and source context. Output topology uses
accepted proposal addresses and checks final materialized node/edge membership.
State validation compares the full native relation proposal and typed source
supports. Engine evidence additionally retains its observation witness in the
recognition record; that witness is not a source EvidenceRecord.

One conservative assembly ledger applies the existing 32 MiB service allowance
to both held/planned source-report copies, retained endpoint references,
recognition reports, topology rows and the final snapshot. Native owner limits
remain active. Real components are counted with JSON field framing before
retention; this is separate from exact artifact sealing and is not a process
resident-memory bound. Cancellation survives canonicalization and final hashing;
failed/cancelled artifact results clear graph/report/topology output.

The namespace service captures the original native publisher after composition.
Pair validation independently rebuilds raw and the four direct stages, finishes
their native source closure, and compares every mandatory full partition with
the supplied graph. It then uses the existing inactive readback and guarded
activation. Native readback hydrates the actual retained source/package owners,
validates project/analyzer identities, and reacquires one immutable pair under

Exact frozen v8 epochs remain distinct from the current v9 catalog. Unsupported
v9 writes refuse without moving Current, changing the epoch or leaving an
operation receipt. Metadata-only raw/direct admission and the legacy artifact
importer remain deferred; the service uses actual native replay plus graph.
