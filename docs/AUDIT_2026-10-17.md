## Current disposition, reviewed at 687049b6

One shared Main/Library analysis, one catalog parse, one final annotation emission,
ordinary native Library generation, Wasm removal and the single Project replay
representation are implemented. E0 envelopes, one-shot replay registries and
Reference Pack administration were removed. These changes do not prove the full
user workflow, donor parity or end-to-end performance.

Ordinary Project reads still reconstruct analysis and graph state. Nested Search
SQLite images, self-sizing pagination, unreadable context rendering, evidence-heavy
setup and protocol limitations remain. Follow the actual consumers in #131/#169,
#122, #200/#201 and #198/#199; do not infer completion from the number of removed files.

The previous version of this reviewed audit had itself become stale: it described
two Emmy engines, an active pack builder and all runtime refactors as pending.
The rewrite basis replaces that status table, rather than adding another diary.

## Corrections that must survive the rewrite

- The XML type-shape vector is charged after the loop. The cited code does not
  establish quadratic complexity or a measured 70–80% saving.
- Recognizer files with `allow(dead_code)` have live callers. Remove unused
  behavior through callers, not by counting lint-suppressed lines.
- The active `generated_api.rs` importer is not the deleted orphan importer.
- Distinct graph records are not necessarily three identical copies. Preserve
  relationships and locations actually consumed by diagnostics/navigation.
- Ketho lowering, corrections, aliases and source maps already exist. Preserve
  their useful semantics instead of writing another importer or evaluator.
- Ordinary DTOs and validated executable owners are different boundaries;
  deleting duplicate wire structs must not bypass constructor invariants.
- Compilation/Clippy is build evidence, not an executed consumer check. #232
  changed rejection phases and left a negative-test defect despite green CI.

User source/configuration stays intact. Derived caches can be rebuilt without
legacy readers, migrations or archive fixtures. Removed platform scope is not
future work to transfer endlessly between Issues. History belongs in Git.
