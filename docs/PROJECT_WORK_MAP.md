# Work map

Choose one task from [REFACTOR_QUEUE.md](REFACTOR_QUEUE.md). Its GitHub Issue
owns scope, current claim and result. Read [AGENTS.md](../AGENTS.md), the Issue
and its named implementation/donor paths.

- [Architecture](ARCHITECTURE.md): product scope and removed features.
- [Completion](PROJECT_COMPLETION_MATRIX.md): existing behavior and remaining user workflows.
- [Audit](AUDIT_2026-10-17.md): verified reduction targets.
- [Execution](EXECUTION_MODEL.md): one worktree, bounded ownership and checks.

[#191](https://github.com/UnknownAlienHuman/WoW-Dev-Framework/issues/191) tracks
reduction; [#125](https://github.com/UnknownAlienHuman/WoW-Dev-Framework/issues/125)
tracks delivery. Earlier package/branch acceptance ledgers do not override the
current scope or revive removed features.
