## Selected structural behavior

The native graph route composes genuine Project/Emmy source facts and independent
recognizer partitions, retaining original source/evidence and accepted proposal
crosswalks. Named/inline XML handlers, source declarations/references, TOC state,
construction and selected signal/hook/library observations are executable. XML
inheritance and methods do not establish effective runtime objects or dispatch.

W1 registers native event observations without inventing an event handler. Its
typed input has no unused declaration crosswalk; actual handler ownership stays
with SetScript/XML. EventRegistry/CVar and custom-signal qualification remain in
#161/#162, and secure-hook callable/signature repair remains in #166.

W6 retains the full LibStub major key, such as `AceAddon-3.0`, and a separate
numeric minor only when exact owner facts prove it. Repeated uses merge bounded
support; neither a hyphen suffix nor a directory name proves a loaded version.
The nonexistent `LibStub.EmbedLibrary` rule is removed. Real AceAddon receiver and
result-zero custody remains NotEvaluated in #159; the capability census must not
describe embed as functional. Wider structural support/mutation acceptance is
tracked by #157/#103.

## Retained operations and compatibility

and reconstruct them from admitted retained input. Physical update, NoChange,
remove/reopen, roots/GC and selected backup/recovery/migration routes have bounded
implementations; complete W13–W16 acceptance remains #108–#111.

Selected Primary continuation retains the original generation, cumulative budget,
response and receipt lineage. `Store::commit_operation` atomically commits its
response/receipt/root/catalog changes and Prepared-to-Completed transition.
Earlier Prepared interruption requires explicit reconciliation; completed
response loss permits exact stored-byte retry. Terminal prune explicitly ends
that retry window. See the
[Service contract](../crates/wow-service/e3/CONTEXT_OPERATIONS.md).
Legacy rootless-history and broader retention qualification remain #110/#122.

Historical report9 global-budget replay13/14/15 keeps its exact reader/query
recipe and original catalogs. Current report10 scalar-constant interpretation
uses replay16. The actual old schema13 archive crosses a frozen V13 Store and
the native acquired-pair reader with original project/analyzer identities; a V16
write is refused without changing Current. See
[replay publication](../crates/wow-project/REPLAY_PUBLICATION.md).
This bounded compatibility proof does not qualify every historical epoch.

## First frontend subset

`wow transport capabilities` reports the immutable selected registry/profile.
`wow mcp --transport stdio --profile mcp-2025-11-25-stdio-v1` exposes only
`wow.status -> frontend_status` and the exact profile resource. It enforces bounded
frames/depth/output, initialize/initialized admission, process-local session
identity, strict request IDs, tool/protocol error separation and checked EOF close.
It does not advertise a Search query operation that has not been implemented.
Broader sessions/documents, daemon/LSP, client conformance and E7-A acceptance
remain in #170/#125; E7-B release/install/update owners remain unimplemented.
