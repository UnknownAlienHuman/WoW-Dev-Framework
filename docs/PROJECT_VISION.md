# Project purpose

Make WoW addon development easier with upstream EmmyLua, a native Rust port of
Ketho's annotation pipeline and useful Blizzard UI source search. Users should
configure ordinary roots/TOC/flavor/library paths, obtain diagnostics, and find
relevant APIs/source without a VS Code dependency.

[ARCHITECTURE.md](ARCHITECTURE.md) defines the current scope and explicit removals.
[REFACTOR_QUEUE.md](REFACTOR_QUEUE.md) defines the work. There is no parallel
platform, provider, cryptographic governance or release-system roadmap.
