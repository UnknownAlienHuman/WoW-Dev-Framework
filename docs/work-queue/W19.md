# W19 — Context semantic packs, exact excerpts and service/CLI operations

State: specified. Priority P1. Dependency: W18/#86 map/skeleton owner; W13/#81 exact acquisition is transitively required. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F08/#68.

## What
Implement ContextSemanticPack, deterministic JSON/Markdown rendering and E3 service operations: status, map, inspect, build, continue, validate and render. Extend the existing wow executable; do not introduce another public binary or a model-based summary path.

## How
In wow-context, assemble immutable items from W18 and exact owner-provided L2 excerpts, retaining identity DAG, source maps, provenance, confidence, conflicts and omissions. Separate semantic bytes/identity from renderer version, redaction and output budgets. Source text is quoted data, never instructions; no fabricated summaries or source-wide dumps. Implement exact byte accounting and explicitly classified token estimates unless a frozen tokenizer proves exact counts. Service resolves selectors once in the documented acquisition order, holds all leases, validates requested capabilities and closes resources on every success/failure/cancel/output-break path. Continuation binds the original universe/profile/selection and cannot silently reacquire a newer current. The app only parses, calls service and serializes documented outcomes.
