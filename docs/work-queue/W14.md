## What
Replace the unconditional full rebuild/fresh false cancellation flag in `wow-project/src/publication.rs` with the owned update model. Preserve the current safe old-generation-on-failure behavior. Explicitly distinguish retaining Library inputs, replacing them and clearing them; an empty vector must not ambiguously mean both keep and clear.

## How
Validate update preconditions and final file state, construct an actual analyzer update batch, and classify invalidation through Lua/virtual unit, TOC/XML, package metadata, analyzer/Library, recognizer and graph-profile dependencies. Reuse only facts with an exact unchanged-input/profile proof; conservatively widen when unavailable. Remove transitive stale facts/edges/source maps, rebind the new generation, then publish the coherent pair through W13. Thread the caller's cancellation and budgets through analyzer, recognizers and publication. An explicit Library-change enum or equivalent versioned request field must preserve old callers through documented conversion. No in-place mutation of visible snapshots or background watcher in this task.
