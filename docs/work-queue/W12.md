State: specified. Priority P1. Dependencies: none for graph owner implementation; W11 provides additional integration producers later. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F08/#68.

## What
Extend existing retained-support explanations into complete owned conflict/derivation records. Current `wow-graph/src/explain.rs` intentionally does not manufacture missing conflict/derivation data. Entity/neighbors/subgraph/axis/path/explain and retained source reads already exist and must not be rebuilt.

## How and files
Add exact assertion/derivation/conflict records to the current proposal/partition materialization model, preserving producer-local IDs through composite origin identities. Validate support chains and conflict scope at publication, not only during rendering. Extend `explain.rs`, `explain/collect.rs` and evidence projection to return actual supporting/rebutting assertions, scoped coverage and explicit omissions under scan/output/depth budgets. Keep graph evidence separate from dereferenced source content and use the existing owned source-detail seam. Update serialization/schema compatibility deliberately; existing retained bundles must remain readable or reject through an explicit version/compatibility outcome. No confidence maximization, silent winner selection or missing-record fabrication.
