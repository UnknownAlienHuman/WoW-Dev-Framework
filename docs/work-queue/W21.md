# W21 — Exact generation-pair lineage, migration and static impact

State: specified. Priority P2. Dependencies: W12/#80 graph conflict/provenance and W13/#81 exact retained generations. W20/#88 search is an optional candidate input, not proof or a graph-owner dependency. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F08/#68.

## What
Implement the E4 graph lineage/migration/static-impact slice and typed service routing. Compare two exact compatible generations; do not infer historical identity from equal names or treat search similarity as accepted lineage.

## How
Add small owned modules under wow-graph for generation-pair binding, candidate production, review/assertions, change classification and bounded static traversal. Reuse graph identities/evidence/conflict records. Deterministic exact proofs and explicit authorized review decisions have separate ceilings; retain rejected/ambiguous candidates and both sides of conflicts. Migration/replacement is a typed relation with its own support, not an automatic edit. Impact traverses allowed exact axes and reports direct/transitive paths, direction, confidence, stop reasons and coverage. Service acquires both retained views, validates review/publication authority and projects results; graph code never resolves current or calls search. Persist only through the owned store handoff, with operation IDs and CAS where effects exist.
