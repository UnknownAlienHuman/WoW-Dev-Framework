State: specified. Priority P2, after functional local owners. Dependencies: W11/#79 executable producers and W12/#80 provenance/conflicts; service persistence uses W13/#81. E4 lineage is not required merely to run recognizer evaluation. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F08/#68.

## What
Implement the first governed E5 slice: corpus/label admission, leakage-safe split validation, real rule evaluation, candidate eligibility and exact partition replacement/deactivation. Do not turn writing missing production code into endless corpus expansion. No real pack is promoted merely by opening or merging this task.

## How
Add owned calibration models/evaluator beside existing wow-recognizers pack/compiler/matcher modules, using exact source/rule/profile/label identities. Group related/derived cases before splitting; distinguish training/development/review/holdout visibility and reject leakage. Count denominators and NotEvaluated/Unknown/Conflict cases explicitly. Run actual producers against admitted corpus bytes and retain per-group errors, near negatives and mutation outcomes. Reviewer independence must come from an actual authorized receipt, never a model-created claim. Compute eligibility without automatically activating a core pack. Service owns authorization, effects and audit; graph partition replacement/deactivation preserves exact provenance, removes owned assertions and downgrades coverage. Candidate, shadow and active states must remain distinct.
