# W13 — Coherent live ProjectStore publication and acquisition

State: specified. Priority P1. Integration dependencies: W03/#71 exact bindings and W12/#80 graph record compatibility. W09–W11 extend supported producers but do not block implementing the existing admitted profile. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F06/#68.

## What
Complete the missing live ProjectView/GraphView publication and read path. Current v7 retained graph publication, membership manifests, SQLite read snapshots, CAS, read-back and reconciliation already exist. Reuse them; a retained graph bundle must not simply be relabeled a live project.

## How and files
Extend the publication bundle in `wow-project/src/publication.rs` and service graph/project acquisition around `wow-service/src/graph/persistence.rs`, using existing `wow-store/src/project` typed ports. Persist the exact identities and owner-validated data needed to acquire immutable project and graph views from one generation. Validate the noncyclic identity order and complete required partition membership before activation. Resolve current once, hold the read snapshot/lease while validating all owners, and expose either the coherent pair or an explicit failed/unavailable result. Reconstruct analyzer-dependent capabilities through the approved exact session path, or leave them NotEvaluated; serialized IDs alone are not executable analyzer state. Keep storage records, hydrated owner views and public DTOs distinct. Preserve exact retained reads and old bundle compatibility through explicit versions.
