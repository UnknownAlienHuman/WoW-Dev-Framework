# W23 — LSP over exact private document overlays

State: specified. Priority P2. Dependencies: W14/#82 update semantics and W22/#90 frontend session/registry. Embedded LSP does not require optional daemon mode. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F08/#68.

## What
Implement the repository-pinned LSP 3.18 profile and immutable per-session unsaved-document overlays. Reuse the single Emmy/project analysis path and existing diagnostics/semantic operations. Advertise only features supported by actual owner capabilities.

## How
Put overlay ownership/update validation in wow-project, typed workspace/session/operation routing in wow-service and protocol framing in apps/wow. Register explicit roots/policies; never guess a WoW install or scan AddOns/editor settings. Bind every document version/change to the exact prior overlay digest and negotiated UTF-8/UTF-16 coordinate conversion. Apply validated ordered edits atomically; skipped/out-of-order/conflicting versions require resynchronization, not a disk fallback. Overlay analysis retains exact published dependency identities and reports partial graph/saved-generation-only capabilities honestly. Save acknowledgment is not disk verification or durable publication. On close/disconnect follow the session policy and destroy unsaved bytes after required leases unless an explicit secure recovery profile authorizes retention. Keep clients isolated; source edits/code actions require their separately defined authorization and are not enabled merely because LSP supports them.

## Acceptance
- [ ] Open/change/analyze/save/close uses actual exact overlays and owner diagnostics, not stale saved-file results labeled current.
- [ ] UTF-8/UTF-16, CRLF, surrogate/byte boundary, out-of-range and stale-version cases reject or resynchronize atomically.
- [ ] Two clients cannot read each other's unsaved source/results; default close removes private overlay retention.
- [ ] Diagnostics/results retain source version; cancellation and output pressure cannot publish obsolete results as current.
- [ ] Capabilities, unsupported operations, save/disk/publication outcomes and edits follow the selected profile.
- [ ] Focused project/service/LSP conformance tests, check, fmt and Clippy pass with exact-head/platform evidence.

Specification only; code/checks NOT-RUN. No editor installation, global PATH changes, background watcher or daemon activation is performed. Full E7-A acceptance remains selected-profile evidence, not a consequence of compiling an LSP executable.
