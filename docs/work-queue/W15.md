# W15 — Complete generation retention and safe garbage collection

State: specified. Priority P1 data integrity. Integration dependency: W13/#81. Baseline `02d893cd3b9c9dd116a3330824b9764c3d5ab919`; audit F06/#68.

## What
Connect existing ProjectStore read snapshots/process-local generation leases to complete retention-root closure and bounded GC. Do not recreate read transactions or claim unsupported external-process SQLite readers must work.

## How and files
Extend `wow-store/src/project` with typed retention/GC plans and service-owned authorization/reporting. Roots include current/last-known-good policy, active generation leases, exact retained selections, in-flight publication/reconciliation and explicitly pinned backup/operation artifacts as defined by the contract. Traverse complete generation→partition→object/epoch membership, preserving shared objects. Plan against exact policy/epoch/root identities, recheck immediately before deletion, then commit guarded bounded batches. Concurrent lease acquisition/publication invalidates stale plans. Retain tombstones/retry state for Windows sharing failures; failure is not successful deletion. Reuse existing generic object-store GC where compatible without leaking raw SQL or domain meaning into generic tables. Never GC by age alone or silently expire live read leases.

## Acceptance
- [ ] Current, pinned and actively leased generations and shared dependencies survive GC; eligible unreferenced data is actually reclaimed.
- [ ] A new lease, publication, policy or epoch change between plan and delete prevents stale deletion.
- [ ] Interrupted bounded batches resume/reconcile without deleting protected data or double-counting effects.
- [ ] Windows sharing failures remain explicit pending outcomes; lease drop/cancellation closes resources correctly.
- [ ] Dry-run and execution reports retain exact root/policy/epoch identities and measured counts.
- [ ] Focused store/service tests, check, fmt and strict Clippy pass; platform cases not executed stay NotEvaluated.
