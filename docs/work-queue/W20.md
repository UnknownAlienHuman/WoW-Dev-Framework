## What

The crate currently has documentation only. Create a real executable vertical slice before workspace activation; no placeholder search adapter.

## How
Follow the declared search dependency/storage boundary and selected FTS5 profile, including its executable feature probe. Build logical documents from admitted owner views, not raw-source inference. Preserve exact shard/profile/field/tokenizer/ranking identities. Keep authoritative exact lookup separate from fuzzy/text/shape candidates; fusion cannot promote candidate scores into proof. Expose lane contributions, canonical tie-breaks, excluded candidates and coverage. Publish indexes only after independent read-back; hold shard leases for bounded result-set materialization and continuations. Cursor identity binds the original universe/query/ranking/result set; no hidden current switch or expanding candidate cap between pages. Add typed service operations and thin app commands, not direct application SQL. No embeddings/reranker/provider is required for the local lane.
