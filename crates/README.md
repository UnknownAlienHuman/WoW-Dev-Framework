# Rust owners

Read [current status](../docs/CURRENT_STATUS.md) before changing a crate. Use
[Implementation](../docs/IMPLEMENTATION.md#code-ownership) for retained
responsibilities and [the baseline audit](../docs/AUDIT.md) only for the commit it
names. Existing package boundaries are not requirements to preserve. Package
READMEs identify reusable code and current removal boundaries; old platform
contracts remain in Git history.
