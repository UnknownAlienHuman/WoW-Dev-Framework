# E6-A error model

**Status:** normative.

`ExternalCandidateBridgeError` carries code, operation/stage, exact descriptor/capability/state/query/result/candidate/artifact IDs, transport/provider error refs, coverage/conflict/loss/privacy/license/budget/cancellation state, and bounded structured arguments.

Recovery classes:

```text
never
after-descriptor-capability-or-profile-fix
after-external-state-rebind
after-query-or-budget-fix
after-provider-transport-recovery
continue-same-exact-state-and-query
```

Default errors redact credentials, private endpoints, source/snippets, private paths, provider cursor bytes, and raw transport handles.
