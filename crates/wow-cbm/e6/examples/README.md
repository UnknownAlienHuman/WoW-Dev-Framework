# E6-A normative fixture shapes

- `provider-descriptor.json` — reviewed descriptor, capability intersection, and forbidden runtime widening.
- `external-state.json` — stable, observed-mutable, opaque, conflict, and invalid generation substitutes.
- `candidate-result-set.json` — Candidate-only normalization, provider-local scores, unverified locators, loss, and explanations.
- `zero-continuation-cache.json` — zero-result semantics, continuation/state/budget binding, cache authority, and optional degradation.
- `CHECKSUMS.json` — prerequisite, adapter, profile, vector, member, and bundle freeze gate.

Implementation-dependent values remain null only while `implementation_state` is `not-started`.
