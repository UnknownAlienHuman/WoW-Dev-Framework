# E2-A normative fixtures

- `registry.json` — initial entity/relation/attribute/axis registry shape.
- `partition.json` — synthetic producer partition with project/load/API assertions.
- `snapshot.json` — immutable graph snapshot/publication/generation closure.
- `query-cases.json` — exact, neighbor, axis, path, subgraph, continuation, and budget requests.
- `conflict-cases.json` — incompatible assertion, cycle, multiplicity, coverage, and producer-removal cases.
- `CHECKSUMS.json` — prerequisite/member/bundle freeze gate.

All implementation-dependent IDs and SHA-256 values remain null only while implementation state is `not-started`.
