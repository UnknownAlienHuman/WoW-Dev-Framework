# Complete Ketho type-catalog probe

The `Native current-source annotations` workflow composes every file currently present under Ketho's `Annotations/Core/Type` directory from one exact, once-resolved donor commit:

- `BlizzardType.lua`
- `EmoteToken.lua`
- `FunctionContainer.lua`
- `GlobalColors.lua`
- `Mixin.lua`
- `Namespace.lua`
- `StringEnum.lua`
- `Structure.lua`
- `UnitToken.lua`

The resources are read as regular Git blobs from the same revision. Dirty worktree files, moving-ref changes between reads, symlinks, path traversal and mixed donor revisions are rejected. The combined run exercises cross-file dependency resolution and collision handling across named aliases, open and closed strings, structures, namespaces, static function containers and global colors.

A successful command may still return the framework's explicit partial status. Duplicate donor declarations, native-name conflicts and unresolved external type references remain source-bound outcomes; they are not silently dropped, repaired or widened to `any`. `cargo xtask verify-library` independently checks the retained resource identities, declaration inventories, final generated bytes, issues and source maps.

Focused string-enum and structure runs remain separate so a failure in the combined inventory cannot hide which parser profile or artifact contract regressed. The combined probe is integration evidence for the selected donor revision, not Blizzard authority and not a permanent assertion that Ketho's directory inventory will never change.
