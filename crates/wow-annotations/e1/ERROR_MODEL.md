# `wow-annotations` E1-C error model

**Status:** normative typed input, semantic, lowering, rendering, source-map, loss, parity, consumer-probe, security, and artifact failure vocabulary.

Human prose is a projection. Tests and callers inspect exact error codes, operation/stage, artifact/reference/profile/model/declaration/type/file/span/loss/parity/consumer IDs, coverage, budgets, and recovery class.

## 1. Error shape

```text
AnnotationError
    code
    stage/operation
    AnnotationBuildRequest/Report/Artifact IDs
    ReferenceView/ProfileId/ReferenceGenerationId
    semantic/type/layout/dialect/docs/source-map/loss/consumer profile IDs
    module/declaration/member/type/doc/restriction IDs
    rendered file/fragment/span IDs
    projection status/coverage/loss IDs
    parity baseline/record/report IDs
    consumer probe request/result IDs
    budget/cancellation state
    structured message arguments
    recovery class
```

Recovery classes:

```text
never
after-request-or-profile-fix
after-reference-capability-or-conflict-fix
after-semantic-or-type-rule-fix
after-rendering-or-sanitization-fix
after-consumer-or-oracle-profile-update
after-artifact-rebuild
after-contract-or-implementation-fix
retry-exact-same-inputs
```

Public errors omit raw source/docs/SQL, private paths/tokens/URLs, excessive generated bytes, user config, and runtime Secret-capable values.

## 2. Request/context errors

### `annotation_build_request_invalid`

Missing/contradictory ReferenceView/profile/profiles/budgets/eligibility inputs.

### `annotation_reference_view_invalid`

View/store/reference manifest/coverage unavailable or invalid.

### `annotation_profile_or_generation_mismatch`

Any input/model/file/map/parity/probe uses another profile/reference generation.

### `annotation_cross_generation_mix_forbidden`

One artifact/model/source map contains mixed generations.

### `annotation_required_reference_capability_unavailable`

Selected projection depends on missing/partial/failed capability; status/loss/NotEvaluated required.

### `annotation_implicit_profile_or_current_forbidden`

Current/latest/default consumer/layout/reference inferred implicitly.

### `annotation_dependency_boundary_violation`

Store/analyzer/service/project/search/app dependency or hidden process/filesystem behavior introduced.

## 3. Semantic model errors

### `annotation_semantic_profile_invalid`
### `annotation_semantic_model_invalid`

Malformed profile/model identity/kind/ordering/capability rules.

### `annotation_module_ownership_invalid`

Declaration belongs to missing/multiple/wrong module.

### `annotation_declaration_invalid`

Missing/contradictory kind/name/owner/signature/reference/status.

### `annotation_declaration_identity_collision`

Distinct semantic declarations share a unique semantic identity.

### `annotation_member_invalid`
### `annotation_member_order_invalid`

Missing/wrong owner/type/ordinal/cardinality/optionality.

### `annotation_type_graph_invalid`

Orphan/cycle/depth/structure/reference/type-kind invariant failure.

### `annotation_documentation_record_invalid`
### `annotation_restriction_projection_invalid`
### `annotation_reference_projection_link_invalid`

Missing exact source/reference/rule/status closure.

### `annotation_selected_input_without_projection_status`

A selected ReferenceView fact/member/type disappeared from status/loss coverage.

### `annotation_semantic_output_without_reference_or_derivation`

Generated semantic element lacks exact input/derivation closure.

### `annotation_reference_conflict_silently_resolved`

ReferenceView Conflict became a declaration/type through first/last guess.

### `annotation_semantic_model_nondeterministic`

Equivalent inputs/profiles produce different semantic IDs/order/digests.

## 4. Type-lowering errors

### `annotation_type_lowering_profile_invalid`
### `annotation_type_lowering_result_invalid`

Malformed source/consumer rule/result/status/loss.

### `annotation_silent_any_fallback_forbidden`

Unresolved/unsupported input widened to `any` without explicit source/loss rule.

### `annotation_silent_unknown_or_omission_forbidden`

Type/member/return/variant omitted or converted to unknown silently.

### `annotation_optionality_nilability_collapse_forbidden`

Optional/missing/nil/default/omitted-return distinctions collapsed without classified loss.

### `annotation_named_type_unresolved`
### `annotation_named_type_ambiguous`
### `annotation_named_type_cross_profile_forbidden`

Exact named target unavailable/conflicted/wrong generation.

### `annotation_union_or_tuple_semantics_invalid`

Variant/order/member/multiple-return semantics lost/changed.

### `annotation_function_or_callback_semantics_invalid`

Receiver/params/returns/variadic/default shape invalid.

### `annotation_enum_or_literal_projection_invalid`

Value/name/base/literal strategy inaccurate.

### `annotation_secret_projection_invalid`

Facet/position/type/runtime semantics incorrectly projected.

### `annotation_runtime_secret_wrapper_or_declassification_claim_forbidden`

Nominal type implies runtime object/constructor/operator/unwrap/safe access.

### `annotation_runtime_whitelist_forbidden`

Permanent spell/data secrecy emitted.

### `annotation_type_budget_exceeded`

Depth/nodes/union/tuple/callback/alias/rendered bytes over profile.

### `annotation_type_lowering_nondeterministic`

Equivalent source/profile yields different type graph/result.

## 5. Dialect/global errors

### `annotation_dialect_profile_invalid`
### `annotation_consumer_dialect_projection_invalid`

Malformed profile/global/consumer mapping.

### `annotation_global_not_source_confirmed`

Global/namespace emitted from editor/default/installed addon/oracle rather than exact reference/profile.

### `annotation_removed_or_wrong_flavor_global_emitted`

Profile isolation violation.

### `annotation_project_or_dependency_global_in_platform_library_forbidden`

Third-party/project global leaked into universal artifact.

### `annotation_editor_global_or_library_mutation_forbidden`

Settings/config/global/library auto-add attempt.

### `annotation_diagnostic_suppression_forbidden`

Renderer/probe changes diagnostic policy to hide incompatibility.

## 6. Layout/rendering errors

### `annotation_layout_profile_invalid`
### `annotation_rendering_profile_invalid`

Malformed path/partition/template/order/consumer/format rules.

### `annotation_artifact_path_invalid`

Absolute/traversal/device/reserved/NUL/overlong/unsafe artifact path.

### `annotation_artifact_path_collision`

Distinct modules/files map to same normalized/case-insensitive path without accepted deterministic rule.

### `annotation_identifier_invalid_or_collision`

Name cannot render exactly/safely or generated aliases collide.

### `annotation_source_text_injection_forbidden`

Source/reference/oracle text changes directive/code/string/comment/file/module structure.

### `annotation_generated_code_shape_forbidden`

Rendered syntax contains statements/templates outside reviewed allow-list.

### `annotation_runtime_body_or_behavior_forbidden`

Generated stub includes source-provided or functional runtime behavior.

### `annotation_documentation_sanitization_failed`
### `annotation_documentation_directive_injection_forbidden`
### `annotation_documentation_truncation_unreported`

Unsafe/unclassified docs rendering.

### `annotation_literal_rendering_invalid`

String/number/literal escape/round-trip mismatch.

### `annotation_rendered_file_invalid`

Encoding/line endings/final newline/trailing whitespace/syntax/length/digest/line count invalid.

### `annotation_rendered_file_budget_exceeded`

Files/declarations/lines/bytes/splits over budget.

### `annotation_rendering_nondeterministic`

Equivalent model/profile yields different file bytes/path/order/digests.

### `annotation_full_source_or_runtime_packaging_forbidden`

Blizzard implementation/source body or analysis artifact added to addon runtime payload.

## 7. Source-map/loss/coverage errors

### `annotation_source_map_invalid`

Map/artifact/file/profile/reference identity mismatch.

### `annotation_generated_span_invalid`

Span out of bounds/misaligned/wrong file digest/column convention.

### `annotation_generated_span_stale`

File changed after span calculation.

### `annotation_material_fragment_unmapped`

Declaration/member/type/doc/restriction fragment lacks exact map/derivation link.

### `annotation_projection_status_invalid`
### `annotation_projection_coverage_invalid`
### `annotation_projection_loss_record_invalid`

Malformed subject/status/profile/consumer/reference/affected-capability closure.

### `annotation_projection_loss_missing`

Unsupported/omitted/approximated/sanitized/consumer-specific/partial input has no loss record.

### `annotation_reference_coverage_overridden_forbidden`

Complete renderer/artifact used to hide partial/conflicted reference source.

### `annotation_sidecar_semantics_silently_ignored`

Mandatory sidecar-only semantics treated as preserved by consumer that does not consume sidecar.

### `annotation_loss_report_truncated_as_complete_forbidden`

Budget truncation hides decisive/blocking loss.

### `annotation_artifact_eligibility_invalid`

Declared fixture/candidate/release-ready state contradicts loss/coverage/security/parity/consumer gates.

## 8. Parity errors

### `annotation_oracle_baseline_invalid`

Unpinned/malformed/wrong source/profile/config/artifact/extractor baseline.

### `annotation_oracle_input_mismatch`

Source/profile/correction/consumer/format inputs differ.

### `annotation_oracle_used_as_authority_forbidden`

Artifact/reference facts overwritten to match oracle.

### `annotation_semantic_parity_record_invalid`
### `annotation_semantic_parity_report_invalid`

Subject/diff/classification/evidence/action/count/digest invalid.

### `annotation_parity_classification_unproven`

Equal/equivalent/our defect/oracle stale/etc. selected without evidence.

### `annotation_byte_parity_as_sole_correctness_forbidden`

Byte/layout equality substitutes for semantic/source/consumer validation.

### `annotation_unresolved_parity_blocker`

Mandatory unresolved/our-defect record prevents declared eligibility.

### `annotation_match_at_any_cost_forbidden`

Renderer/source output silently changed from oracle without contract/source review.

### `annotation_consumer_profile_invalid`
### `annotation_consumer_probe_request_invalid`

Diagnostics disabled/reclassified silently.

### `annotation_consumer_semantic_mismatch`

Expected type/signature/member/source behavior differs.

Declared consumers interpret shared artifact differently.

### `annotation_consumer_probe_budget_exceeded`
### `annotation_consumer_probe_untrusted_output`

External probe time/memory/output/schema/path/security issue.

### `annotation_consumer_update_incompatible`

Mandatory behavior regressed; last-known-good retained.

## 10. Security/privacy errors

### `annotation_untrusted_instruction_ignored`
### `annotation_filesystem_network_process_shell_editor_client_access_forbidden`

### `annotation_unbounded_input_or_output_forbidden`

### `annotation_build_late_work_after_cancel_forbidden`

Late render/map/probe/report work after cancel.

### `annotation_semantic_manifest_invalid`
### `annotation_file_manifest_invalid`
### `annotation_consumer_manifest_invalid`
### `annotation_artifact_manifest_invalid`
### `annotation_artifact_manifest_digest_mismatch`

Identity/count/reference/checksum/profile closure invalid.

### `annotation_partial_artifact_exposure_forbidden`

Candidate files/maps presented as final/release-ready.

### `annotation_physical_or_semantic_determinism_unproven`

Required canonical output differs or proof missing.

## 12. Deferred capability errors

### `annotation_full_framexml_ui_graph_not_implemented_e1_c`
### `annotation_search_or_lineage_not_implemented_e1_c`
### `annotation_runtime_probe_not_implemented_e1_c`
### `annotation_final_pack_assembly_not_implemented_e1_c`

Map to typed unavailable, never empty success.

## 13. Fatal vs scoped

### Fatal artifact build

```text
context/profile mismatch
semantic model/reference closure invalid
source/code/path injection
artifact/file/source-map manifest invalid
mandatory consumer/parity/security/determinism failure
```

### Module/declaration/consumer scoped

```text
unsupported type/member/docs/restriction/consumer syntax
reference partial/conflict
nonmandatory parity difference
```

Retain useful output only with explicit partial/loss/eligibility state.

### Probe/parity scoped

Probe failure can leave candidate artifact valid for another consumer/profile but cannot satisfy failed declared gate.

## 14. Recovery

- request/context -> exact valid ReferenceView/profiles;
- semantic/lowering/rendering -> fix profile/implementation and rebuild;
- reference partial/conflict -> rebuild ReferenceData or accept explicit partial policy;
- sanitization/security -> fix renderer/profile; never bypass;
- oracle/consumer -> repin/reprobe/classify and retain last-known-good;
- source map -> rerender/recompute maps from final bytes;
- loss/eligibility -> add exact projection/sidecar or revise declared capability with review;
- deferred -> later owning milestone.

## 15. Error tests

Every used code requires:

- exact operation/stage/context/subject/profile IDs;
- dedicated fixture/mutation;
- projection coverage/loss/eligibility impact;
- no partial final artifact on fatal/cancel;
- deterministic serialization;
- no raw/private/source/config leak;
- recovery class;
- no oracle/editor/process/storage/search/runtime escape.
