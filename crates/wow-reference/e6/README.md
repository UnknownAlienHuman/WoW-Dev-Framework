# `wow-reference` E6 supporting seam

E6-B can ask `wow-reference` to map one external `UnverifiedProviderLocator` to an exact retained ReferenceView entity through [`EXTERNAL_CANDIDATE_MAPPING_HANDOFF.md`](EXTERNAL_CANDIDATE_MAPPING_HANDOFF.md).

The ReferenceView remains platform authority; the provider and mapping receipt remain Candidate discovery/mapping evidence. No provider transport, current selection, or reverse dependency on service/applications is added.
