# E5-B error model

**Status:** normative.

`E5BServiceError` carries code, operation/stage, exact known IDs, owner/authorization/vault/store error references, coverage/conflict/blocker/privacy/license state, retention/audit/closure/recovery state, and bounded structured arguments.

Recovery classes are: `never`, `after-request-profile-or-selector-fix`, `after-owner-capability-or-retention-fix`, `after-candidate-evidence-fix`, `after-review-authorization-fix`, `after-holdout-authorization-vault-audit-fix`, `after-license-privacy-notice-fix`, `retry-same-operation-id-and-request-digest`, `reconcile-exact-owner-effect`, `continue-with-exact-retained-snapshot`, `safe-cleanup-or-quarantine`, and `E5C-review-required`.

Default errors redact source, hidden labels, holdout membership, confidential notes, credentials, signatures, private paths, and raw owner handles.
