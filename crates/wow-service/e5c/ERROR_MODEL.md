# E5-C error model

**Status:** normative.

`E5CServiceError` carries code, operation/stage, exact known IDs, owner/signing/authorization/observation/store error refs, coverage/conflict/blocker/privacy/license/distribution state, retention/audit/closure/recovery state, and bounded structured arguments.

```text
never
after-request-selector-or-profile-fix
after-submission-or-evidence-fix

```

Default errors redact source, cohort membership, credentials, private keys, confidential notes, private endpoints/paths, and raw owner handles.
