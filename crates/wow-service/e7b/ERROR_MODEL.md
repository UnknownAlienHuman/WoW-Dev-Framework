# E7-B release lifecycle error model

**Status:** normative.

`ReleaseLifecycleServiceError` carries code, operation/stage, exact known source/plan/build/artifact/evidence/signature/bundle/candidate/channel/manifest/install/update/rollback/revocation/retirement IDs, owner/adapter/store error references, coverage/conflict/blocker/security/license/resource/cancellation/reconciliation/close state, and bounded structured arguments.

Default errors redact source bodies, secret material, private endpoints, command/environment data, local private paths, user data, signing/distribution internals, support-bundle contents, provider handles and unbounded logs/stacks.
