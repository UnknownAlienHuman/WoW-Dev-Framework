# Determinism and rebuild comparison

**Status:** normative E1-D reproducibility classification.

## Purpose

One successful build does not prove determinism. E1-D performs controlled repeated builds and compares declared equivalence classes.

## Execution profiles

At minimum:

```text
workers=1, canonical input order
workers=2, reversed/shuffled independent input order
workers=N, seeded shuffled order
```

The same logical source/profile/component/layout inputs are used. Execution profile affects scheduling only and does not enter logical pack identity.

## Comparison classes

### Semantic identity

Must be equal:

- ProfileIdentity / ReferenceGenerationId;
- normalized raw/fact/correction/conflict/coverage manifests;
- annotation semantic model/type/status/loss/parity/probe semantic IDs;
- pack member logical identities and gate decisions.

### Canonical bytes

Must be byte-identical:

- canonical JSON manifests/reports/sidecars;
- rendered annotation files;
- source maps/loss/parity records when canonical;
- license/provenance manifests generated by the framework.

### Content-addressed objects

Logical uncompressed ObjectId must be equal. Encoded payload bytes must be equal only under the same frozen encoding profile.

### SQLite

Must be logically equivalent through store manifests, row/object counts/digests, integrity reports, and golden queries. Physical database bytes are:

```text
guaranteed-equal
observed-equal-not-contractual
different-but-logically-equivalent
not-compared
```

Only the store runtime/profile can declare `guaranteed-equal`.

### Directory metadata

Destination root, mtime, owner, inode, and staging names are noncanonical.

### Archive bytes

Not evaluated unless a frozen container profile exists.

## Difference record

```text
RebuildDifference
    domain/member/subject
    left/right build and identity
    comparison class
    expected/allowed/forbidden
    normalized field/byte/object/store difference
    owning component
    evidence/reports
    blocker policy
```

No prose-only diff.

## Gate

A validated-local pack requiring reproducibility passes only when:

- all mandatory semantic identities equal;
- all canonical byte classes equal;
- object/store differences conform to declared profiles;
- no unexplained order, path, clock, environment, provider, or worker difference;
- every allowed physical difference is recorded and does not change logical identity.

## Mutation cases

- hash-map or SQL row order changes output;
- worker completion changes declaration/file order;
- source manifest enumeration changes registration order incorrectly;
- timestamps/temp roots enter manifest;
- annotation split boundary depends on scheduling;
- SQLite bytes differ while code claims byte reproducibility;
- compression timestamp/implementation changes archive bytes;
- one build omits a loss/conflict record;
- parity/probe records ordered by process completion.

## Performance

Timing and resource observations are supplemental. Performance variance does not change deterministic identity. Report corpus, hardware/runtime, warmup, samples, and percentiles separately.
