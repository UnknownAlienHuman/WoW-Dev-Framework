# E7-A service fixture shapes

- `protocol-profiles.json` — exact LSP/MCP profiles, initialization/capability decisions, and unsupported-version cases.
- `session-overlay-cases.json` — exact workspace binding, rebind, document version, edit, save-observation, close, and overlay cases.
- `operation-cases.json` — analysis, cancellation, progress, backpressure, authorization, privacy, and projection cases.
- `CHECKSUMS.json` — prerequisite implementation, official specification, profile, platform, vector, member, and bundle freeze gate.

Implementation-dependent IDs, official-spec digests, expected bytes, and SHA-256 values remain null only while `implementation_state` is `not-started`.
