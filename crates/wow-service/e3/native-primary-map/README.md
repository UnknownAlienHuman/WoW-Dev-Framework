# Frozen native primary map fixture

This 2026-10-11 fixture is a reviewed synthetic native-owner example for #122.
It freezes the first closed profile, exact request and canonical service envelope.
It does not certify Gethe, Ketho, WoW API parity, a client or a full project map.

The actual service test publishes one tiny physical Lua project through
ProjectPublisher/source graph/native ProjectStore, reopens it with original
provenance, then publishes a changed second generation. The frozen request reads
the first exact retained generation while observing the second Current. No host
path or source body is present in these files. The private store/host/CLI transport
export stays outside the distributable fixtures.

Review checked exact native root, two adjacent nodes, two Owns edges, original
producer proposal/accepted receipts, complete evidence/source custody, five
explicit omissions, Partial status and checked closure. Repeated native reads
produced identical bytes. The envelope contains 80831 bytes; its ProjectMap
contains 78745 bytes. This is encoded output accounting, not heap/peak telemetry.

`CHECKSUMS.json` lists exact lengths and SHA-256 for the three members. The
focused service test compares generated bytes against these files; changes require
review of the actual selected behavior and identity, never automatic blessing.
Broader E3 fixtures and qualification remain open.
