# Addon and load context

Delivery state: [CURRENT_STATUS](../../docs/CURRENT_STATUS.md). Project owns
bounded root/file admission, TOC/load selection, exact bytes, plan identity,
selected source authority, source projection and source-located failures.

Slice 1A uses one profile-free target/scope-bound physical projection and returns a
direct prepared value to Service. It wraps the existing component-wise no-follow
root opener; the legacy ambient `ProjectInputDirectory::open` is not the ordinary
checker boundary. Later slices add dependency/order, full XML/chunk context,
channel, triggers, bindings and secure/special cases.

Exact requirements, ceilings and classifications live in
[IMPLEMENTATION](../../docs/IMPLEMENTATION.md#first-implementation-slice) and the
[queue](../../docs/REFACTOR_QUEUE.md#1-first-usable-ordinary-addon-check). Do not
copy them here or create publication/proof/replay replacements.
