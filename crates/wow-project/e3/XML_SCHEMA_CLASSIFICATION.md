# Selected XML schema classification

Issue [#117](https://github.com/UnknownAlienHuman/WoW-Dev-Framework/issues/117)
owns implementation and acceptance. This is the selected static policy; an
admitted catalog and executable composed path are still required.

The profile binds the genuine native source snapshot, source profile, admission
and content-manifest digests, explicit XSD member selection, catalog digest,
classification policy version and exact reviewed component IDs. Decoding a
selection does not construct the admitted catalog or reviewed owner. Replay
re-admits both against the same retained source and verifies their identities.
Unselected configurations retain their existing bytes and readers.

Classification consumes retained XML document indexes in their own namespace
scope, with package/document/occurrence and generation bindings supplied by the
existing graph owner. It does not parse addon XML again.

The finite classes have these definitions:

- **Frame-like:** both a unique observed global-element SubstitutionGroup path
  to the selected frame-element anchor and a unique observed Type/Base path to
  its selected named-complex-type anchor are required. Either path alone is
  insufficient. Derivation edges retain their typed Extension/Restriction
  parent chain.
- **Region-like:** the profile selects the exact Layers/anonymous-type/Sequence/
  local-Layer/anonymous-type/Sequence/Choice chain and its five unique observed
  element-reference/type witnesses. Same-type aliases may share schema class;
  this does not establish placement in that Choice.
- **Structural, script and load/reference:** only explicit reviewed global
  declaration anchors supply these categories. Metamodel kinds and a general
  element-name table do not classify an occurrence.

Unknown qualified names, unsupported or unresolved paths, source occurrences
of abstract declarations and cycles remain explicit unknowns. Multiple candidate
declarations or incompatible class witnesses retain conflict; no winner or
complement class is inferred. Unknown names have exact scoped counts.
Cancellation, identity mismatch and budget refusal propagate as operation
failures rather than becoming unknown semantic outcomes.

Occurrence identity, schema class, template declaration, XML `inherits`, lexical
containment and runtime instance are separate. Source/schema evidence can be
Proven within its exact scope; runtime existence, class and dispatch remain
NotEvaluated. Name, suffix, capitalization, parent tag, `mixin` and `inherits`
spelling cannot supply class authority.

One cumulative bounded classification ledger covers the retained documents;
composition also retains its existing producer and result allowances. Output
contains per-occurrence outcomes, typed schema witnesses, profile/catalog and
index identities, coverage/conflicts and proposal/rejection support. Distinct
class and occurrence entities use an exact relation definition under #114 in
the selected XmlStructure producer. No additional aggregate profile or separate
schema CLI substitutes for the graph/service/replay route. The real #116
candidate must consume the classification manifest before full acceptance.
